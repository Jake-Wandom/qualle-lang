# Changelog

All notable changes to this project will be documented in this file.

## [1.0]

### Added - 18.10.2026

- Official 1.0 Release
- 1.0 supports:
  1. QIR base and adaptive profile
  2. Optional adaptive capabilities including classical computations, loops, dynamic qubits, and IR-defined functions
  3. Generation of .bc or .ll QIR compliant LLVM files
  4. LLVM optimisation passes
